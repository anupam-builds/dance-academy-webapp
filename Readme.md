# Atharv's Dance Academy - Full-Stack Web Application

A full-stack, responsive web application built to manage a dance academy's online presence. This application features secure user authentication, session management, dynamic routing, and a modern, interactive UI. 

## 🚀 Features
* **User Authentication:** Secure registration and login functionality with password validation.
* **Session Management:** Protected routes (Dashboard, Services, Class Info) accessible only to authenticated users via `express-session`.
* **Database Integration:** MongoDB integration using Mongoose for storing user credentials and contact form submissions.
* **Dynamic Views:** Server-side rendering using the Pug templating engine for modular and dynamic HTML generation.
* **Modern UI/UX:** Fully responsive design built from scratch with custom CSS, featuring interactive hover states, flexbox layouts, and FontAwesome integration.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Pug, JavaScript, FontAwesome
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Middleware:** Body-Parser, Express-Session
